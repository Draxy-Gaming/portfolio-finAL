## 2025-02-27 - Custom Button Accessibility Patterns
**Learning:** In this application, many custom interactive elements (like the 'Copy Email', 'Read More', and form submission buttons) lacked standard keyboard focus indicators and accessibility landmarks for dynamic state changes.
**Action:** When creating new custom interactive components, ensure `focus:outline-none focus-visible:ring-2 focus-visible:ring-[color]` is applied for keyboard navigability. Additionally, use `aria-live="polite"` on buttons where text changes dynamically (like loading or copied states), and explicitly set `aria-hidden="true"` with empty `alt=""` on purely decorative icon images inside these buttons.
